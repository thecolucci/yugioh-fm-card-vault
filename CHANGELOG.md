# Changelog

Todas as alterações relevantes do Yu-Gi-Oh! FM Card Vault serão registradas neste arquivo.

## [0.0.82] — 2026-08-04

Primeira consolidação privada do projeto para controle de versão.

### Produto

- Card Book responsivo com catálogo visual das 722 cartas.
- Busca, ordenação e filtros por categoria, tipo, campo, custo, ATK e DEF.
- My List com favoritos persistidos localmente.
- Overlay completo de detalhes, navegação anterior/próxima e retorno contextual.
- Recipes, Fusions e Equips com filtros e paginação próprios.
- Guardian Stars, Fields, previews in-game e fallback para cartas sem modelo 3D.
- Sistema visual inspirado em Forbidden Memories com sprites, glow, pulse e shine sweep.

### Dados e qualidade

- Base normalizada de 722 cartas e respectivas relações.
- Pipeline documentado de captura, normalização, publicação e auditoria.
- Correções de imagens de cartas, Guardian Stars, Fields e fundos dos vídeos.
- Base responsiva revisada para desktop e mobile.

### Repositório

- Estrutura preparada para repositório privado.
- README profissional com identidade, screenshots, microvídeos e documentação de uso.
- Iniciador independente de caminhos locais.
- Fontes PSD, caches, arquivos temporários e metadados locais excluídos do versionamento.
- Autoria registrada como Colucci Design & Comunicação Ltda.
