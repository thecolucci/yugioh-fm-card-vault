# Configuração recomendada do repositório

## Nome

`yugioh-fm-card-vault`

O nome é curto, memorável e combina a identificação do jogo com a ideia de um acervo completo de cartas.

## Descrição curta

Card Book moderno e responsivo de Yu-Gi-Oh! Forbidden Memories com 722 cartas, Passwords, Starchips, filtros avançados, fusões, equips e prévias in-game.

## Tópicos sugeridos

`yu-gi-oh` · `forbidden-memories` · `card-book` · `card-database` · `fusion` · `react` · `typescript` · `pixel-art` · `fan-project`

## Configuração inicial

- Visibilidade: privada.
- Branch padrão: `main`.
- Releases, Issues e Discussions: desabilitados enquanto o projeto estiver privado e em desenvolvimento.
- Wiki e GitHub Pages: desabilitados até a definição da estratégia de publicação.
- Nenhuma licença pública enquanto o uso dos assets de terceiros estiver em revisão.
- Autor: `Colucci Design & Comunicação Ltda`.

## Antes da primeira publicação

- Publicar a partir de um histórico limpo, contendo somente a versão autoral consolidada.
- Confirmar que arquivos PSD, caches, fontes de extração e configurações locais continuam ignorados.
- Confirmar que nenhum arquivo rastreado contém caminhos pessoais, credenciais ou metadados de ferramentas internas.
- Executar build, testes, lint e auditoria dos dados.
- Revisar o README no modo de visualização do GitHub e testar os links dos vídeos.
